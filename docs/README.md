# 概述

- 工程名称：photoFrame 相框
- 这是一个图片处理后端服务

# 功能需求设计

一期计划以最小可用架构实现系统基础框架和基础水印功能。

- 水印相框
  - 自定义水印相框
    - 自定义部分字段（一期）
      - 字体
    - 内容
            - logo
            - 位置
      - 自适应的百分比水印（一期）
      - 基础相框类型（一期）
        - 白框
        - 模糊
        - 景深色卡
      - 水印分类
        - 艺术水印（一期）
        - 版权水印（二期）
  - 可配置的水印模板
  - 可分享复用的配置（二期）
- 图库管理
  - 上传下载（一期）
  - 第三方OSS/图床
  - EXIF 读取并清理（一期）
  - 裁切、压缩和格式转换
  - 自动处理（命名、分类）
- 图片编辑
  - 自动生成明信片（三期）
- 基础设施
  - 认证鉴权
    - 基础认证（一期）
    - 三方登录
  - 用户管理
  - 站内信


# 预期技术栈统计

- FastAPI
- SQLModel
- SQLAlchemy
- Pillow
